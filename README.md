# 🌍 Tripadvisor Clone

A responsive Tripadvisor-inspired travel website built using **HTML5** and **CSS3**. This project features a modern user interface with travel destinations, Travellers' Choice sections, image hover effects, animated icons, and a fully responsive layout for desktop, tablet, and mobile devices.


## ✨ Features

- Responsive Navigation Bar
- Modern Hero Banner
- Travel Inspiration Section
- Travellers' Choice Awards
- Popular Destinations
- Image Zoom on Hover
- Animated Favorite (Heart) Icon
- Smooth CSS Hover Effects
- Responsive Design (Desktop, Tablet & Mobile)
- Clean Footer with Quick Links

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Animations
- Media Queries
- Font Awesome

## 📱 Responsive Design

- 💻 Desktop
- 📱 Tablet
- 📲 Mobile

## 🎯 Project Objective

To recreate a modern travel website inspired by Tripadvisor while demonstrating responsive web design, interactive UI components, and clean front-end development practices.
